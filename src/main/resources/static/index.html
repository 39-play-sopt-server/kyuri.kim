게시판 서버

SOPT 서버 파트 1주차 과제 · 헥사고날 아키텍처로 구현한 게시판 API

서버가 정상적으로 실행 중입니다

API 목록

POST/api/posts게시글 작성
GET/api/posts게시글 목록 조회
GET/api/posts/{id}게시글 상세 조회
PUT/api/posts/{id}게시글 수정
DELETE/api/posts/{id}게시글 삭제

응답 형식

모든 응답은 공통 응답 객체(ApiResponse)로 내려갑니다.

  • 성공 여부, 상태 값, 메시지, 데이터를 함께 담아요.
  • 요청이 잘못되었거나 게시글이 없으면 에러 코드와 메시지가 응답으로 와요.

게시글 규칙

  • 제목은 비워둘 수 없고 최대 50자까지 입력할 수 있어요.
  • 내용은 비워둘 수 없고 최대 500자까지 입력할 수 있어요.
  • 카테고리는 FREE, INFO, CAREER 중 하나여야 해요.
데이터는 메모리에 저장되므로 서버를 종료하면 사라집니다.
